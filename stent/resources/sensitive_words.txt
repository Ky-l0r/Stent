# Stent 发布前检查 · 中文敏感词与风险规则库
# ---------------------------------------------------------------------------
# 用途：stent/services/precheck.py 的本地规则数据源，用于发布前敏感词 / 违禁词 /
#       极限词 / 导流 / 洗稿 / 低质内容扫描。纯离线，不联网、不调用 LLM。
#
# 文件格式：
#   1. 以 # 开头的行是注释，加载时忽略；
#   2. 「== 分节名 ==」标记一个分节，其后的词条归属该分节；
#   3. 每行一个词条，按「子串命中」匹配；含英文字母的词条大小写不敏感；
#   4. 词条两端空白会被去掉，词条内部允许含空格（如「由 AI 生成」）。
#
# 分节 → 命中级别 / 机器可读代码（见 precheck.py 的 SECTION_RULES）：
#   广告法极限词 ............ error / extreme_word
#   极限词（需人工复核）..... warn  / extreme_word_soft
#   虚假宣传与绝对承诺 ...... error / false_claim
#   医疗夸大 ................ error / medical_claim
#   医疗术语（需人工复核）... warn  / medical_term
#   金融风险 ................ error / finance_risk
#   平台违禁 ................ error / banned_content
#   国家机构与特供 .......... error / state_agency
#   歧视与引战 .............. error / hostile_content
#   导流与联系方式 .......... warn  / contact_diversion（小红书/抖音升为 error）
#   平台限流与过度营销 ...... warn  / marketing_heavy
#   内部信息与密钥 .......... error / secret_leak
#   技术词（需人工复核）..... warn  / tech_term
#   AI 自曝措辞 ............. info  / ai_disclosure
#   洗稿特征词 .............. warn  / washing_pattern
#   低质内容特征 ............ info  / low_quality
#
# 维护建议：
#   - 广告法极限词分节只放「无正当理由」的绝对化短语；「最好 / 最强 / 唯一」这类
#     日常口语里常见的词一律放到「极限词（需人工复核）」，避免发布被误拦。
#   - 医疗、金融两个分节误报率天然偏高，命中后请结合上下文人工判断。
#   - 平台限流词表随时效变化，建议每季度复核一次。
# ---------------------------------------------------------------------------
